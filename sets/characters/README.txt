Place paired character images here.
File naming convention:
  <name>-1.png (LEFT half) and <name>-2.png (RIGHT half)
OR
  <name>-left.png (LEFT half) and <name>-right.png (RIGHT half)

Both halves of a pair must be the same dimensions.
Supported formats: .png, .jpg, .jpeg, .webp (transparent PNGs recommended).
